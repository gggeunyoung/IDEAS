# 목표 실행 운영 규칙 — 2026-10-14

## 목적과 현재 지원 범위

사용자의 목표를 실행 가능한 작은 결과로 만들고, 실제 검사와 다른 AI의 검토를 거쳐 개선한다. 계획이나 질문만 남기고 종료하지 않는다.

첫 구현은 GPT·Claude 구독, 웹 시제품과 Node 내장 테스트를 지원한다. AI는 구조화된 파일 내용을 제출하고 서버가 방의 `outputs/<ID>/workspace/revision-<N>/`에 실제 파일을 저장·검사한다. 원본 편집, 임의 셸, 패키지 설치, 운영 배포, 다른 OS 테스트 격리는 지원하지 않는다. 이 문서를 읽는 것만으로 권한이나 타이머가 생기지는 않는다.

## 공통 규칙

1. 목표를 최소 결과와 완료 조건으로 바꾼다. 기능 하나라도 실제로 사용할 수 있는 결과를 우선한다.
2. 사소하고 되돌릴 수 있는 선택은 합리적으로 정해 진행하고 가정을 기록한다. 질문의 답 없이 할 수 있는 구현·검증을 먼저 끝낸다.
3. 한 AI가 파일을 작성하고 다른 AI가 독립적으로 검토한다. 같은 파일을 동시에 수정하지 않는다. 검토자의 승인만으로 실행 성공을 주장하지 않는다.
4. 서버의 실제 파일과 검사 결과를 다음 호출에 전달한다. 실패한 검사·구체적 검토 사항이 남으면 수정하고 재검사한다.
5. 테스트가 없거나 실패하면 완료 및 현장 검증 대기로 표시하지 않는다. 테스트 통과도 전체 사용자 경험 검증과 구분한다.
6. 실행 시간과 AI 호출 횟수에 상한을 둔다. 초기 기본값은 60분·12회이며 사용자 지정 범위는 10~120분·4~24회다. 완료하면 남은 예산을 쓰지 않고 종료한다. 개별 목표 호출은 전체 남은 시간 안에서 최대 10분까지 허용한다.
7. 진행되는 수정에 예산을 사용한다. 같은 파일을 피드백 후 3회 연속 제출하거나 실행 실패가 3회 연속 발생하면 이유를 기록하고 종료한다. 장애 판정도 바로 멈추지 않고 가능한 다른 접근을 시도한다.
8. 구독의 잔여 토큰은 모델의 보고 사용량만으로 추정하지 않는다. 정확한 잔여 한도를 알 수 없음을 표시하고, 실제 한도 오류를 기록한다. 별도 과금 API로 전환하지 않는다.
9. 실제 사람·카메라·공간의 측정은 코드 작성과 다르다. 가능한 시뮬레이션과 자동 검증을 먼저 끝내고, 남은 현장 절차를 재현 가능하게 남긴다.
10. 시작, 구현 파일 생성, 검사 결과, 다른 AI 검토, 수정, 최종 종료 사유를 회의실과 파일에 저장한다. 브라우저 연결이 끊겨도 맥 작업을 자동 취소하지 않는다.
11. 사용자 중단, 예산 도달, 실행 장애를 완료와 구분한다. 맥 서비스 재시작 후 실행 중 작업은 중단 상태로 복구한다. 자동 재개 기능은 아직 없으며 같은 과금 호출을 몰래 반복하지 않는다.
12. 기존 원본, 인증정보, 다른 방의 변경을 보존한다. 생성 코드의 테스트는 macOS 격리 안에서 실행해 계정 홈·다른 프로젝트 접근, 작업 폴더 밖 쓰기, 네트워크 접근을 제한한다.

## 종료 상태

- **완료**: 실제 파일 생성, 관련 자동 검사 통과, 다른 AI 검토 완료, 남은 구현 및 현장 검증 항목 없음. 자동 검사 범위와 사람의 확인 여부는 별도 기록한다.
- **현장 검증 대기**: 구현과 자동 검사·검토를 마쳤고, 실제 장비·사람의 동작을 확인하는 절차만 남음.
- **실행 예산 도달**: 시간 또는 호출 상한에 도달함. 해결 불가능이나 완료로 표현하지 않음.
- **해결 장애 / 진전 없이 반복 / 실행 실패**: 가능한 다른 접근을 시도한 기록과 장애·미완료 항목을 보존함.
- **사용자 중단 / 워커 재시작 중단**: 이미 만든 결과와 실제 실행 기록을 보존함.

## 짧은 요청 양식

> 목표: 무엇을 사용할 수 있게 만들지.
> 최소 결과: 이번 실행에서 꼭 작동해야 하는 기능.
> 완료 조건: 어떤 실제 검사와 결과로 판단할지.
> 선택 범위: AI가 알아서 정할 수 있는 사항과 지켜야 할 제약.
> 현장 조건: 알고 있는 장비·공간 정보. 모르면 가정을 표시하고 가능한 구현부터 진행.

시간·호출 상한은 화면 설정을 사용한다. 메시지의 숫자를 화면 설정과 다르게 적으면 시스템의 실제 설정이 우선하며 시작 시 사용 예산을 표시한다.
