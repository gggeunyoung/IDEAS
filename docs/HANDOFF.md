
Node.js 22 이상을 사용한다. Codex가 설치돼 있지 않으면 공식 설치 또는 LOCAL_CODEX_BIN 설정이 필요하다. macOS에서는 설치된 앱 번들의 CLI를 찾고 그 외에는 PATH의 codex를 사용한다. Claude는 해당 노트북의 본인 claude.ai 계정으로 로그인한다. 다른 노트북의 인증 설정을 복사하지 않는다.
