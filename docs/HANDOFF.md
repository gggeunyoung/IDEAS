## 다른 노트북 / 다른 Claude 계정에서 이어가기

```sh
git clone https://github.com/gggeunyoung/IDEAS.git
cd IDEAS
npm run setup:local
npm run login:claude
npm run login:gpt
npm start
```

Node.js 22 이상을 사용한다. Codex가 설치돼 있지 않으면 공식 설치 또는 LOCAL_CODEX_BIN 설정이 필요하다. macOS에서는 설치된 앱 번들의 CLI를 찾고 그 외에는 PATH의 codex를 사용한다. Claude는 해당 노트북의 본인 claude.ai 계정으로 로그인한다. 다른 노트북의 인증 설정을 복사하지 않는다.

비공개 작업 저장소는 GitHub 접근 권한이 있는 계정으로 따로 클론한다. Claude 구독 계정이 다른 것과 GitHub 저장소 접근 권한은 별개다. 경로·인증·기기별 방 등록 정보는 새 컴퓨터에서 다시 설정한다. Windows 등 다른 OS의 설치와 CLI 실행은 아직 별도 실환경 검증하지 않았다.
