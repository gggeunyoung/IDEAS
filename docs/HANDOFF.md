## 검증된 기존 기능

- 맥 localhost 웹 서버 + Codex/Claude Code 구독 CLI 호출. 앱 화면 자동 조작이 아니다. 모델 추론은 제공자 서비스에서 일어난다.
- GPT·Claude 실제 답변, 웹 검색·출처 반환, 독립 제안·상호 검토를 확인했다.
- 파일 협업은 계획 2회 → 작성자 초안 → 다른 AI 검토 → 작성자 수정, 최대 5회 호출이다.
- 파일 내용은 공식 구조화 출력으로 받고 서버가 경로·비밀정보·크기를 검사해 저장한다. CLI에 프로젝트 원본 편집이나 셸 실행 권한을 열어 둔 것은 아니다.
- 초안과 수정본을 구분하고 수정본은 재검토 전임을 표시한다. 자동 실행·테스트·배포·원본 적용까지 완료했다고 주장하지 않는다.
- 기존 검증은 자동 테스트 24개와 실제 GPT 작성 → Claude 검토 → GPT 수정의 두 Markdown 파일 결과였다.

## 방별 구조와 검증

- room-registry.mjs: 등록된 저장소·로컬 경로만 방 ID로 연결한다. 등록 목록 .runtime/rooms.json은 기기별 정보이며 Git에서 제외한다.
- server.mjs: roomId에 따라 자료, 현재 대화, 결과 파일과 회의록의 루트를 분리한다. 사용자 임의 경로를 요청으로 받지 않는다.
- 등록된 프로젝트의 현재 대화는 .ideas/session.json에 저장한다. 기기 내부 상태이므로 공유하지 않는다. 완료한 회의록은 conversations/에, 생성 파일은 outputs/에 저장한다. 방 분리·origin·경로·Git 저장을 포함한 현재 자동 테스트는 33개를 통과했다.
- room-git.mjs: 현재 방의 명시된 문서·회의록·결과만 검사해 커밋·정상 푸시한다. 다른 변경, .env, 기기 상태, 미리 스테이징한 변경을 섞지 않는다.
- 첫 시험용 비공개 저장소: https://github.com/gggeunyoung/ideas-room-lab
- 이 맥의 시험 폴더: /Users/kimgeunyoung/ideas-room-lab
- 새 컴퓨터의 방 등록: node scripts/rooms.mjs add "AI 협업 실험실" "$HOME/ideas-room-lab"

## 다른 노트북 / 다른 Claude 계정에서 이어가기

```sh
git clone https://github.com/gggeunyoung/IDEAS.git
cd IDEAS
npm run setup:local
npm run login:claude
npm run login:gpt
npm start
```

Node.js 22 이상을 사용한다. Codex가 설치돼 있지 않으면 공식 설치 또는 LOCAL_CODEX_BIN 설정이 필요하다. macOS에서는 설치된 앱 번들의 CLI를 찾고 그 외에는 PATH의 codex를 사용한다. Claude는 해당 노트북의 본인 claude.ai 계정으로 로그인한다. 다른 노트북의 인증 설정을 복사하지 않는다.

비공개 작업 저장소는 GitHub 접근 권한이 있는 계정으로 따로 클론한다. Claude 구독 계정이 다른 것과 GitHub 저장소 접근 권한은 별개다. 경로·인증·기기별 방 등록 정보는 새 컴퓨터에서 다시 설정한다. Windows 등 다른 OS의 설치와 CLI 실행은 아직 별도 실환경 검증하지 않았다.

## 배포와 미완료 항목

- 웹 화면 배포 주소: https://ideas-nine-opal.vercel.app/
- Vercel의 인증된 중계를 통해 맥 워커에 연결했다. 웹 비밀번호 로그인 후 어느 기기에서든 이 맥의 방과 GPT·Claude 회의를 사용할 수 있다. 운영 문서는 docs/remote-connection.md다. 로컬은 http://127.0.0.1:3030/이다.
- 원격 로그인, 맥 작업 ID/결과 저장, 외부 중계, 중단/재조회, 중계 주소 재등록을 구현했다. LaunchAgent 자동 실행과 caffeinate 잠자기 방지를 설정했다. 현재 Quick Tunnel은 SLA가 없어 고정 이름의 정식 중계로 교체하는 운영 개선이 남았다.
- Gemini 대체 CLI 연결, 원본 프로젝트 자동 편집·실행·테스트, 여러 대화 세션 UI는 미완료다.
- 최종 답변 후 단발 10분 자동 푸시 타이머도 아직 연결되지 않았다. 이전 반복 감지 자동화를 재활성화하지 않는다.
- 방 생성·클론·Git 저장은 사용자 명시 요청으로만 실행한다. 타이머나 반복 자동 실행이 됐다고 주장하지 않는다.
