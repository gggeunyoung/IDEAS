GitHub 저장소 연결

계정 연결 안내

터미널에서 아래 명령으로 계정에 로그인한 뒤 상태를 새로고침하세요.

GPT: npm run login:gpt
Claude: npm run login:claude

Gemini의 개인 계정용 기존 CLI 지원은 종료됐습니다. 현재 구독 모드에서는 선택할 수 없으며 Antigravity CLI 연결이 필요합니다. 재로그인으로 해결되지 않습니다.

구독 모드는 각 CLI의 계정 사용량 한도를 사용합니다. API 키로 자동 전환하지 않습니다. 앱과 동시에 사용하면 한도를 공유할 수 있습니다.

구독 모드가 앱과 동일한 모델·기능을 보장하지는 않습니다.

API 모드는 .env의 API 키를 사용하며 별도로 과금합니다. 데모는 실제 AI를 호출하지 않습니다.
