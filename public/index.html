프로젝트 회의실

회의 참가자

웹 시제품·Node 내장 테스트를 실제 파일로 만들고 검사합니다. 예산 안에서 수정·검토를 반복하며 원본은 별도 보존합니다. 완료·현장 검증 대기·예산 도달을 구분합니다.

Claude와 GPT가 교대로 조사·반론·보완을 이어가고 자료·기획을 저장합니다. 리서치는 최소6차례와 근거·대안·반론·보완·기획의 교차 확인을 거쳐야 완료됩니다. 차례마다 자동 커밋하며 원래 브랜치와 푸시는 건드리지 않습니다. 에이전트 작업은 토론보다 구독 사용량이 많습니다.

조사가 필요하면 검색합니다. 검색어는 외부 검색 서비스로 전송됩니다.

한 번에 최대 6회 호출. 자동 반복하지 않습니다.
원본 파일은 수정하지 않습니다.

프로젝트 자료 선택

선택한 파일만 AI에게 전달합니다. 최대 8개 · 합계 32,000자. 비밀정보가 없는 자료를 선택하세요.

저장된 파일 결과

초안과 수정본을 따로 보관합니다. 원본에는 적용하지 않습니다.

계정 연결 안내

터미널에서 아래 명령으로 계정에 로그인한 뒤 상태를 새로고침하세요.

GPT: npm run login:gpt
Claude: npm run login:claude

Gemini의 개인 계정용 기존 CLI 지원은 종료됐습니다. 현재 구독 모드에서는 선택할 수 없으며 Antigravity CLI 연결이 필요합니다. 재로그인으로 해결되지 않습니다.

구독 모드는 각 CLI의 계정 사용량 한도를 사용합니다. API 키로 자동 전환하지 않습니다. 앱과 동시에 사용하면 한도를 공유할 수 있습니다.

구독 모드가 앱과 동일한 모델·기능을 보장하지는 않습니다.

API 모드는 .env의 API 키를 사용하며 별도로 과금합니다. 데모는 실제 AI를 호출하지 않습니다.
