# IDEAS · AI 공동 회의실

프로젝트별 회의실 대시보드에서 저장소를 선택하고, 기존 계정으로 로그인한 **Codex / Claude Code**에 웹에서 질문하고, 독립 제안과 상호 검토를 한 화면에서 봅니다. 어느 기기에서든 원격 회의실에 로그인하면 이 맥의 에이전트들이 실제 작업을 처리합니다. 앱 화면을 클릭하거나 답변을 긁지 않고 공식 CLI의 출력으로 연결합니다. 맥에서 개인 작업과 함께 사용할 수 있으며 사용량 한도와 네트워크는 공유합니다.

## 2026-10-12 연결 상태 수정

GPT는 ChatGPT 구독 로그인, Claude는 Claude 구독 로그인과 실제 응답을 확인했습니다. Gemini도 Google 로그인 설정은 저장됐지만 실호출에서 `UNSUPPORTED_CLIENT`가 반환됐습니다. 개인 계정의 기존 Gemini CLI 지원이 종료돼 구독 참가자로 활성화하지 않습니다. 이전의 Gemini 재로그인 안내를 정정합니다. [Google 공식 종료 공지](https://github.com/google-gemini/gemini-cli/discussions/28017)에 따라 Antigravity CLI 연결이 필요하며, 아직 그 어댑터는 구현하지 않았습니다. Gemini API 모드는 별도로 남아 있고 자동 전환하지 않습니다.

## 시작하기 (현재 검증 환경: macOS, Node.js 24)

```sh
npm ci
npm run setup:local
npm run doctor
npm start
```

[회의실 열기](http://127.0.0.1:3030/). Node.js 22 이상이 필요합니다. 원격 연결 주소 저장에는 @vercel/blob을 사용합니다. 설치 명령은 Claude Code 2.1.296와 Gemini CLI 0.63.0을 무시되는 `.local-tools/`에 설치합니다. Codex는 이 맥에 설치된 앱 번들의 CLI를 우선 사용하고, 없으면 PATH에서 찾습니다. 다른 환경에서는 Codex 공식 설치 후 `LOCAL_CODEX_BIN`을 지정할 수 있습니다.

Windows(2026-10-14 확인)에서는 `npm run setup:local`이 설치 대신 Codex 앱(`%LOCALAPPDATA%\OpenAI\Codex\bin`)과 Claude 앱(`%APPDATA%\Claude\claude-code`, Store 설치는 `%LOCALAPPDATA%\Packages\Claude_*\LocalCache\Roaming\Claude\claude-code`) 또는 Claude Code 기본 설치(`~\.local\bin`)에 포함된 최신 `.exe`를 찾아 보여 줍니다. 없으면 `LOCAL_CODEX_BIN`/`LOCAL_CLAUDE_BIN`을 지정합니다. 목표 실행 모드의 테스트 격리는 macOS 전용이라 Windows에서는 AI 호출 전에 거절합니다.

현재 GPT는 **ChatGPT 구독 로그인과 실제 CLI 응답**을 확인했습니다. 브라우저 질문 → GPT 답변 → 회의록 저장/다운로드, 예시 파일 선택 → 독립 제안 → 작성자 초안의 전체 흐름도 실호출로 확인했습니다. Claude도 구독으로 실제 응답을 확인했습니다. Gemini CLI는 설치와 로그인 설정이 있지만 개인 계정 경로가 지원 종료돼 실제 응답을 받지 못했습니다. 세 AI의 실제 상호 검토 완료를 의미하지 않습니다.

## 계정 연결

```sh
npm run login:gpt
npm run login:claude
```

각 명령에서 본인의 구독 계정으로 직접 로그인한 후 웹의 **로그인 상태 새로고침**을 누르세요. Claude는 claude.ai 계정을 선택합니다. Gemini 개인 구독의 기존 CLI는 지원 종료돼 재로그인을 요청하지 않습니다. 앱에 로그인돼 있어도 CLI에 별도로 로그인해야 할 수 있습니다. 계정 토큰이나 API 키를 채팅에 붙여넣지 마세요.

- **기존 구독:** ChatGPT 로그인 Codex, Claude 계정 로그인 Claude Code를 사용합니다. Google OAuth Gemini CLI의 개인 구독 경로는 종료되어 비활성 상태입니다. CLI의 기본 모델을 사용하므로 앱에서 고른 모델·기능과 동일하다고 보장하지 않습니다. Gemini의 로그인 파일 존재를 연결 성공으로 간주하지 않습니다.
- **API:** 별도의 `.env` API 키와 제공자별 모델을 사용합니다. 앱 구독과 별도 과금입니다. 기본 모델을 바꾸면 요금 추정은 미확인으로 표시됩니다.
- **데모:** 실제 AI를 호출하지 않습니다. 화면에 표시되는 Claude/Gemini 데모 문구는 실제 AI의 답변이 아닙니다.

구독 모드에서는 API 키와 과금용 환경 변수를 자식 프로세스에 전달하지 않고, API 인증 상태를 준비된 구독으로 인정하지 않습니다. 오류·한도 초과 시 API로 자동 대체하지 않습니다. 구독 한도는 다른 앱 사용과 공유할 수 있으며, 제공자 계정의 추가 사용/초과 사용 설정은 별도로 확인해야 합니다. Google AI Pro 구독의 웹앱 한도와 Gemini CLI 한도는 같은 개념이 아닙니다.

공식 안내: [Codex 인증](https://learn.chatgpt.com/docs/auth), [Codex 비대화형 실행](https://learn.chatgpt.com/docs/non-interactive-mode), [Claude Pro/Max 인증](https://code.claude.com/docs/en/authentication), [Claude CLI](https://code.claude.com/docs/en/cli-reference), [Gemini CLI 인증](https://geminicli.com/docs/get-started/authentication/).

## 프로젝트별 회의실과 다른 AI의 인수인계

IDEAS 폴더는 회의실 프로그램 개발용입니다. 실제 프로젝트는 사용자 홈 아래의 별도 Git 저장소/폴더에 연결합니다. 로컬 또는 원격 첫 화면의 대시보드에서 방을 선택하면 자료·현재 대화·결과 저장·Git 작업이 해당 프로젝트로 분리됩니다.

**새 회의실 연결**에는 README가 있는 GitHub 저장소의 HTTPS 주소와 방 이름을 입력합니다. 맥이 홈 아래로 클론하며, 동일한 origin의 기존 폴더는 연결하고 다른 폴더를 덮어쓰지 않습니다. GitHub 저장소 자체를 웹 버튼이 자동 생성하는 기능은 아닙니다. 이미 클론한 프로젝트는 다음 명령으로 연결할 수 있습니다.

```sh
node scripts/rooms.mjs add "회의실 이름" /absolute/project/path
node scripts/rooms.mjs list
```

등록 목록 `.runtime/rooms.json`은 기기별 정보로 Git에서 제외합니다. 현재 대화는 프로젝트의 `.ideas/session.json`에 저장하며, 이 역시 기기 상태이므로 제외합니다. 등록된 작업 방의 완료 회의록은 `conversations/`, 파일 초안·수정본·검토 의견은 `outputs/`에 저장합니다. IDEAS 개발 방의 기존 결과는 artifacts/deliverables를 유지합니다.

**대화·결과 커밋/푸시**는 그 방의 README·운영/인수인계 문서·회의록·결과만 검사해 현재 브랜치의 기존 origin에 일반 푸시합니다. 미리 스테이징한 변경·비밀정보·심볼릭 링크·관련 없는 변경을 섞지 않습니다. 자동 10분 타이머와 별개의 명시적 버튼 동작입니다. 한 번에 한 작업만 실행하므로 방 전환이나 Git 저장을 진행 중인 AI 작업과 동시에 수행하지 않습니다.

다른 노트북/Claude 계정은 [인수인계 문서](docs/HANDOFF.md), AGENTS.md, CLAUDE.md, 날짜별 conversations 요약을 먼저 읽습니다. 작업 저장소도 따로 클론하고 기기에서 방을 다시 등록합니다. 인증 파일은 전달하지 않습니다. 구독 계정과 GitHub 저장소 접근 권한은 별개입니다. 각 방의 현재 대화는 분리돼 있지만, 같은 방의 여러 과거 대화 세션을 고르는 UI는 아직 추가하지 않았습니다.

## 에이전트 팀: 프로젝트 폴더에서 Claude·GPT가 직접 작업 (2026-10-14 첫 버전)

작업 방식에서 **에이전트 팀 · 프로젝트 폴더에서 직접 작업**을 고른다. 기존 구독의 GPT·Claude를 함께 선택하고 먼저 시작할 에이전트, 최대 시간(30/60/120/180분), 최대 차례(4/8/16/30)를 정한다. GitHub 저장소가 연결된 프로젝트 회의실에서만 실행하며 회의실 앱 자체(IDEAS 방)는 수정하지 않는다.

- 회의실이 프로젝트 안에 `.ideas/team/<ID>/workspace` Git 작업 트리와 `ideas/team-<ID>` 브랜치를 만든다. 사용자의 현재 브랜치·폴더는 바꾸지 않고, `.ideas/`는 그 저장소의 로컬 `.git/info/exclude`에 추가한다.
- 두 에이전트는 교대로 그 폴더의 파일을 직접 읽고 만들고 명령을 실행한다. 차례가 끝날 때마다 팀원과 사용자에게 할 말, 상태(계속/완료 제안/사용자 결정 필요), 다음 부탁을 남긴다. 회의실은 변경을 에이전트 이름으로 자동 커밋하고, 다음 에이전트에게 새 대화와 커밋 목록만 전달한다. 각 에이전트의 CLI 세션은 이어서 사용한다.
- 한 에이전트가 완료를 제안하고 다른 에이전트가 추가 변경 없이 확인해야 **완료 합의**로 끝난다. 사용자 결정이 필요하면 멈추고, 다음 메시지를 보내면 같은 브랜치·세션으로 이어간다. 새 브랜치로 시작하는 옵션도 있다. 실패 3회 연속·변경 없는 차례 3회 연속·예산 도달은 각각 구분해 기록한다.
- 권한: Codex는 공식 `workspace-write` 샌드박스(작업 트리 쓰기, 네트워크 차단)로 실행한다. Windows에서는 Codex 앱이 설정한 `windows.sandbox` 값만 개인 설정에서 가져온다. Claude는 작업 폴더 편집과 `node`·`npm test`·`npm run`·읽기용 git 명령만 허용하며 권한 우회 옵션은 쓰지 않는다. Claude의 명령은 OS 샌드박스가 아니라 허용 목록으로만 제한된다. `.env`·키 형태 파일은 커밋하지 않는다. 푸시와 원래 브랜치 병합은 자동으로 하지 않는다.
- 에이전트는 한 차례에도 여러 번 모델을 호출하므로 토론보다 구독 사용량이 많다. 화면에 차례별 입력(캐시 포함)·출력 토큰을 표시하지만 남은 구독 한도는 알 수 없다.
- 팀 기록은 `.ideas/team/<ID>/chat.md`, 상태는 `.ideas/team/state.json`이다. 결과 확인 후 사용자가 브랜치를 병합하거나 버린다.

## 파일 협업 사용법

### 목표 실행: 작은 결과를 만들고 검사·검토·수정 반복

작업 방식에서 **목표 실행 · 구현 → 검사 → 검토 → 반복**을 선택한다. 기존 구독의 GPT·Claude 2명과 검토 옵션을 켜고 작성자를 정한다. 실행 시간(20/60/120분)과 호출 상한(6/12/24회)을 선택한다. 기본은 60분·12회이며 각 AI 호출이 하나씩 계산된다.

AI가 웹 시제품·Node 내장 테스트의 파일 내용을 제출하면 서버가 해당 방 `outputs/<ID>/workspace/revision-<N>/`에 실제 저장한다. JS 문법 검사와 `.test.mjs` 테스트를 macOS 격리 안에서 실행하고 다른 AI가 파일·검사 결과를 검토한다. 구현 문제를 지적하면 예산 안에서 다시 작성·검사·검토한다. 완료·현장 검증 대기·예산 도달·실행 실패를 구분하고 초안·최종 파일·검사 기록·종료 상태를 보존한다. 테스트 통과를 브라우저나 실제 카메라 측정 완료로 확대하지 않는다.

최종 결과에 index.html이 있으면 **작업 중인 맥에서 시제품 열기** 링크를 제공한다. 미리보기는 인증된 회의실과 다른 localhost:3032에서 실행하며 이 맥에서만 열린다. 다른 기기의 회의실 조회·실행은 기존 Vercel 링크로 가능하고, 파일은 다운로드할 수 있다. 시제품의 원격 웹 배포는 자동으로 수행하지 않는다.

첫 범위는 웹 시제품·Node 내장 테스트다. 원본 자동 편집·임의 셸·패키지 설치·다른 OS 격리·작업 재시작 후 자동 재개까지 구현한 것은 아니다. 맥 서비스 재시작 중 실행은 중단 상태로 보존한다. [운영 규칙](docs/goal-execution-policy.md)을 참고한다.

1. 연결 방식은 **기존 구독**, 참가자는 **GPT와 Claude**, 작업 방식은 **파일 협업 · 작성 → 검토 → 수정 → 저장**을 선택합니다.
2. 초안 작성자를 정하고 **다른 참가자의 검토 받기**를 켭니다. 자료 선택에서 사용할 문서를 고릅니다. `examples/portfolio-brief.md`는 이 프로젝트 소개를 시험할 수 있는 확인된 사실 목록입니다.
3. “선택한 자료로 portfolio.md와 next-actions.md를 만들어줘”처럼 파일 결과를 요청합니다. 독립 계획 2개 → 한 작성자 초안 → 다른 AI 검토 → 같은 작성자 수정본, 최대 5회 호출로 끝납니다.
4. **저장된 파일 결과**에서 초안/수정본 보기, 각 파일 미리보기·다운로드, 전체 파일 묶음(JSON) 다운로드를 사용할 수 있습니다. 브라우저를 새로 열어도 서버의 최근 30개 결과를 조회합니다.

파일은 `deliverables/<UUID>/draft/`와 `final/`에 따로 저장합니다. 해당 폴더는 Git에서 제외합니다. 작성 AI가 구조화된 JSON으로 파일 내용을 반환하고 서버가 경로·내용 검사를 거쳐 파일을 저장합니다. 원본 프로젝트를 직접 수정하거나 임의 명령을 실행하지 않습니다. 이 방식은 CLI에 모든 에이전트 도구를 개방하거나 앱의 기존 설정을 복제한 것과 다릅니다.

검토자 실패 또는 수정 실패 시 초안을 보존하며 수정본으로 표시하지 않습니다. 수정본은 **검토 반영 수정본 · 재검토 전**으로 표시합니다. 작성자가 반영 과정에서 새 오류를 만들 수 있으므로 최종 검증 완료라고 표시하지 않습니다. 내용은 사용자가 확인한 뒤 원본에 적용합니다. 코드 파일도 텍스트로 저장할 수 있지만 생성 코드를 자동 실행·테스트·배포하지 않습니다.

한 작업은 최대 5개의 텍스트 파일, 파일당 16,000자, 합계 32,000자로 제한합니다. 숨김 경로·상위 경로·환경/인증 관련 이름·실행 스크립트 확장자·일부 비밀정보 패턴을 거절합니다. 모든 개인정보를 자동 판별하는 것은 아니므로 비밀정보 없는 자료를 선택하세요. 저장 파일은 브라우저에서 HTML로 실행하지 않습니다. 구조화 출력은 [Codex 비대화형 실행](https://learn.chatgpt.com/docs/non-interactive-mode)과 [Claude CLI](https://code.claude.com/docs/en/cli-reference)의 공식 옵션을 사용합니다.

## 웹 검색과 대화가 실행되는 곳

회의실의 **웹 검색 허용**은 구독 모드에서 기본으로 켜져 있습니다. 리서치·최신 정보·출처 확인이 필요하면 Codex의 live 웹 검색, Claude Code의 WebSearch/WebFetch를 사용합니다. 별도 검색 API 키를 추가하지 않았고 API 모드로 자동 전환하지 않습니다. 검색어는 외부 검색 서비스로 전송되므로 파일의 개인정보·비밀정보를 검색어에 넣지 않도록 지시합니다. 검색을 끄면 해당 호출의 검색 도구도 비활성화합니다. API/데모 모드의 검색 연결은 아직 구현하지 않았습니다.

답변 아래에 **검색 도구 호출 횟수**, **페이지 확인 도구 호출 횟수**, **답변의 출처 링크**를 표시합니다. 호출 기록은 CLI 이벤트에서 집계하며, 도구 호출이 성공했거나 모든 출처가 검증됐다는 보장은 아닙니다. Codex는 검색·페이지 열기를 같은 `web_search` 이벤트로 보고하므로 모두 검색 도구 호출에 집계합니다. 출처 링크는 답변에 적힌 URL입니다. 2026-10-12 GPT와 Claude가 실제 검색 도구를 사용해 Node.js 공식 문서를 찾고 출처를 반환한 것을 확인했습니다. 공식 설정: [Codex 웹 검색](https://learn.chatgpt.com/docs/web-search), [Claude 검색 도구](https://code.claude.com/docs/en/tools-reference).

실행 흐름은 **웹 입력 → 맥의 Node 서버 → Codex/Claude Code CLI → 각 제공자의 AI 서비스 → 회의실과 결과 파일**입니다. 모델 추론은 제공자 서비스에서 이뤄집니다. 로컬 ChatGPT·Claude 앱 창에 입력하거나 스크래핑하는 방식이 아니며 앱을 열어 둘 필요가 없습니다. 같은 구독 계정은 사용하지만 그 앱의 채팅 목록과 회의 기록을 동기화하지 않습니다.

각 CLI 호출은 임시 작업공간의 일회성 실행입니다. Codex `--ephemeral`, Claude `--no-session-persistence`를 사용하므로 CLI에서 다시 여는 별도 회의 세션을 만들지 않습니다. 회의실이 이전 대화를 다음 호출에 전달합니다. 현재 기록은 브라우저, **회의록 내보내기**, 맥의 **artifacts/<UUID>.md**, **결과물 다운로드**에서 확인합니다. artifacts는 이 Codex 대화 요약인 conversations와 별개이며 Git에 포함하지 않습니다.

## 회의 흐름과 파일 충돌 방지

1. 로그인한 참가자를 선택하고 질문을 한 번 보냅니다. 각 참가자는 다른 AI의 이번 답변을 보지 않고 독립적으로 제안합니다.
2. **토론**은 성공한 독립 답변을 같은 묶음으로 전달하여 상호 검토합니다.
3. **초안 만들기**는 지정한 한 명만 독립 제안을 모아 초안을 작성하고, 나머지 성공한 참가자가 그 초안을 검토합니다. 자동 수정/최종 합의까지 강제로 이어가지 않습니다.
4. 회의당 최대 6회 호출하고 종료합니다. 추가 방향은 사용자가 다음 메시지로 정합니다.

**자료 선택**에서 고른 파일만 서버가 읽어 프롬프트에 첨부합니다. 최대 8개, 파일당 48KB, 합계 32,000자입니다. 다른 폴더를 자료로 사용하려면 `.env`에 `IDEAS_PROJECT_ROOT=/absolute/project/path`를 설정하고 서버를 재시작하세요. 비밀정보 없는 파일을 선택하세요. 환경 파일·숨김 경로·node_modules·심볼릭 링크·일부 비밀정보 패턴은 거절하지만 패턴 검사가 모든 개인정보나 비밀정보를 찾는 것은 아닙니다. 목록은 최대 200개, 깊이 5단계까지만 제공합니다.

CLI는 매 호출 새 임시 폴더에서 실행합니다. Codex는 사용자 설정/규칙을 무시하고 읽기 전용 샌드박스를 사용하며 셸·앱·플러그인 등 실행 기능을 비활성화합니다. Claude는 safe mode, 도구/MCP 제한, 훅 비활성화를 적용합니다. Gemini 개인 구독의 기존 CLI는 실행 전에 차단합니다. 자료는 사본으로 주어지고 **원본 프로젝트에는 쓰지 않습니다**. Claude의 실제 응답은 로그인 후 확인했습니다. Antigravity 연결은 아직 추가하지 않았습니다. 이는 OS 수준의 완전한 격리 컨테이너를 뜻하지 않습니다.

회의 결과는 무시되는 `artifacts/<UUID>.md`에 저장하고 **결과물 다운로드**로 받습니다. 전체 브라우저 대화는 **회의록 내보내기**로 받을 수 있습니다. 새 회의는 브라우저 기록만 지우며 기존 결과 파일은 삭제하지 않습니다. 저장 실패/참가자 실패는 화면에 남깁니다. 모델 출력은 HTML로 실행하지 않습니다.

원본 프로젝트의 자동 코드 편집까지 확장할 때는 참가자별 Git worktree와 한 명의 통합 담당자를 두어야 합니다. 현재 버전은 자기소개서/계획/문서/코드 파일을 별도 결과 폴더에 생성하고 검토·수정하는 단계까지이며, 원본 코드 편집이나 병합을 구현했다고 주장하지 않습니다.

## 다른 노트북에서 쓰기와 배포

[원격 회의실](https://ideas-nine-opal.vercel.app/)에서 회의실 전용 비밀번호로 로그인합니다. 비밀번호는 이 맥의 .runtime/remote-login.txt에서 확인합니다. 다른 노트북에는 CLI나 작업 폴더가 필요하지 않습니다. 실제 자료 읽기, 구독 CLI 실행, 결과 저장과 Git 작업은 맥이 맡습니다.

Vercel은 웹 화면과 인증된 API 중계를 배포합니다. 맥은 Cloudflare 중계를 바깥으로 연결하고, 주소가 바뀌면 비공개 Vercel Blob에 다시 등록합니다. AI 작업은 맥의 작업 ID로 실행하므로 화면을 닫아도 계속될 수 있고 이전 작업 다시 조회와 중단을 지원합니다.

[원격 연결 운영 문서](docs/remote-connection.md)에 구조, 로그인, 실행·해제·재연결·비용·검증 범위를 기록했습니다. 이 맥의 서비스 상태는 npm run service:status로 확인합니다. 서비스는 맥 로그인 시 자동 실행하며, 실행 중 자동 잠자기를 방지합니다. 덮개 닫힘·수동 잠자기·전원 종료·인터넷 단절은 막지 않으며 이때는 회의할 수 없습니다.

현재 중계는 개발용 Quick Tunnel이므로 무중단 운영을 보장하지 않습니다. 고정 이름의 정식 Tunnel은 다음 운영 개선입니다. 다른 물리적 노트북에서는 아직 직접 시험하지 않았습니다. 공개 Vercel 링크를 통해 실제 GPT·Claude 독립 제안과 상호 검토를 확인했습니다. 유료 플랜 전환이나 별도 AI API 결제는 하지 않았습니다.
