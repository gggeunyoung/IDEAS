# 2026-10-19 대화 기록

## 사용자 의도
- 긴 회의 중 AI가 응답/작업 중인지 알아볼 수 있게 진행 표시를 개선해 달라고 요청했다.

## 에이전트 제안과 구현
- 회의실 상단에 참가자별 작업 현황과 차례·경과 시간·답변 수·마지막 연결 확인을 표시한다.
- 실제 CLI 이벤트의 검색·읽기·파일 수정·명령 실행·답변 생성만 표시한다. 보고가 없으면 대기로 안내한다.
- 연결 재시도를 AI 활동과 구분하고, 재접속한 방의 진행 작업을 자동 조회한다.
- 도구 인자·명령 출력·추론·인증정보는 진행 이벤트에 넣지 않는다.

## 확정된 결정
- 진행 중인 은행 리서치를 업데이트 때문에 중단하지 않는다.
- 기존 작업의 기록되지 않은 시작 시각이나 세부 단계를 추측하지 않는다.

## 검증과 미해결 사항
- 별도 UI 검증 서버에서 실제 AI 호출 없이 병렬 활동 표시, 타이머, 종료 후 버튼 복원을 확인했다.
- 자동 테스트94개 중93개 통과·1개 플랫폼 조건 건너뜀. 정적 빌드 통과. 실제 자식 프로세스의 종료 전 활동 수신, 회의 HTTP 스트림 전달, Claude 스트림 최종 결과 호환, 재조회 시 대화 보존·중복 방지, 연결 지연과 종료 시각을 검사했다.
- 배포·백엔드 반영 결과는 완료 후 추가 기록한다.

## 다음 행동
- 변경을 검증·배포하고 실제 원격 회의에서 표시를 확인한다.
