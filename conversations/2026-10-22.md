
## 맥 직접 작업 재개

### 사용자 의도
- 단순 대화가 아니라 에이전트가 실제 PC에서 파일·터미널 작업을 수행하길 요청했다. 집 Wi-Fi에서 진행하려고 중지한 후 “이어서해”로 재개했다.

### 구현 및 확인
- 자율 협업에 맥 직접 작업/프로젝트 제한 실행 범위를 추가했다. 기본 웹 선택은 맥 직접 작업이다.
- GPT workspace-write + 추가 폴더 + 터미널 네트워크, Claude restricted + 필수 OS sandbox + 샌드박스 내 일반 명령을 연결했다. 샌드박스 밖 재시도/권한 우회 옵션은 사용하지 않는다.
- 추가 폴더는 프로젝트 .ideas/pc-work이며 자동 Git 저장에서는 제외한다. npm/pip 캐시도 이 경계 안에 둔다.
- 실행 범위 변경 시 CLI 세션을 재생성한다. 추가 폴더의 변경도 진전으로 계산한다. 중단 시 부모 CLI가 먼저 종료해도 남은 프로세스 그룹을 강제 종료한다.
- 실제 구독 호출로 GPT(gpt-6.1-sol), Claude(claude-opus-5-5) 각각 파일 작성, node 계산 검사, npm 레지스트리 접속, 추가 폴더 저장에 성공했다. 무해한 허용 경계 밖 파일 쓰기는 둘 다 OS에서 차단됐다.

### 확정된 범위와 한계
- 맥에서 CLI 에이전트가 실행된다. GUI 앱을 원격 조종하는 구현이나 전체 홈 폴더 쓰기 권한은 아니다. GUI/브라우저 조작 도구는 미연결 상태로 화면에도 명시한다.
- 원래 프로젝트 브랜치는 유지하며 팀 작업은 별도 Git 작업 트리에서 순서대로 진행한다.

### 다음 행동
- 웹→원격 작업→실제 파일·검사→결과 반환 통합 검증과 공개 배포 반영을 확인한다.
