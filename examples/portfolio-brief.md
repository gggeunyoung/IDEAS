# IDEAS 프로젝트 소개 작성용 확인된 자료

이 자료는 기능 시험을 위한 프로젝트 사실 목록이며 사용자의 경력·수상·취업 이력을 담지 않습니다.

- IDEAS는 서로 다른 AI의 독립 제안과 상호 검토를 한 웹 화면에서 확인하는 로컬 프로토타입이다.
- Node.js 서버와 HTML/CSS/JavaScript 화면을 사용한다.
- 기존 구독 계정으로 로그인한 Codex와 Claude Code를 호출한다.
- GPT와 Claude의 실제 응답, 상호 검토, 웹 검색과 공식 출처 반환을 확인했다.
- 사용자가 선택한 텍스트 자료만 AI에 전달한다.
- 원본 프로젝트 파일은 수정하지 않는다.
- Gemini 개인 구독의 기존 CLI 경로는 지원 종료로 비활성 상태이다. 대체 연결은 아직 미구현이다.
- 원격 배포, 클라우드 워커, 사용자 인증, 전체 프로젝트 자동 편집·실행·테스트는 아직 구현하지 않았다.
- 파일 협업은 한 작성자가 파일 내용을 생성하고 다른 AI가 검토한 뒤 작성자가 수정한다. 서버가 초안과 수정본을 별도 폴더에 저장한다. 수정본은 아직 재검토되지 않았음을 표시한다.
- 성능 개선 수치, 사용자 수, 사용 시간 절감률, 배포 실적은 아직 측정하지 않았다. 추측하여 숫자를 넣지 않는다.

요청할 수 있는 결과물: portfolio.md(소개·문제·구현·한계)와 next-actions.md(검증·다음 행동).
